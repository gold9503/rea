# REA Studio

브라우저에서 바로 실행되는 **무료 오픈소스 멀티트랙 오디오 워크스테이션(DAW)** 입니다.
설치, 계정, 라이선스 키가 필요 없고 빌드 과정도 없습니다. MIT 라이선스로 누구나 자유롭게 사용·수정·배포할 수 있습니다.

전문 DAW(예: Avid Pro Tools)에서 널리 쓰이는 **작업 방식**(편집 창 / 믹스 창, 녹음 대기, 그래버·셀렉터·가위 도구, 인서트 이펙트, 바운스)을 참고해 처음부터 새로 만든 독자적인 프로그램입니다.
상용 제품의 코드·디자인·상표는 사용하지 않았으며, 해당 제품과 아무 관련이 없습니다.

## 실행 방법

### 1) 그냥 열기
`index.html`을 Chrome / Edge / Firefox 로 열면 됩니다. (재생·편집·바운스 가능)

### 2) 녹음까지 쓰려면 로컬 서버로 열기
마이크 사용은 브라우저 보안상 `https://` 또는 `http://localhost` 에서만 허용됩니다.

```bash
python3 -m http.server 8000
```

그다음 브라우저에서 `http://localhost:8000` 을 엽니다.
GitHub Pages 등 아무 정적 호스팅에 올려도 그대로 동작합니다.

### 3) 데스크톱 앱 (macOS `.app` / Windows `.exe`)

GitHub 저장소의 **Releases** 페이지(`desktop-build-…`)에서 내려받습니다. 브랜치에 푸시할 때마다 GitHub Actions(`.github/workflows/desktop.yml`)가 실제 macOS·Windows 머신에서 새로 빌드합니다.

| 파일 | 용도 |
| --- | --- |
| `REA-Studio-<버전>-mac.dmg` | macOS (Intel + Apple Silicon). 열어서 `REA Studio.app`을 응용 프로그램 폴더로 끌어 놓기 |
| `REA-Studio-<버전>-mac.zip` | 같은 `.app`을 zip으로 묶은 것 |
| `REA-Studio-Setup-<버전>.exe` | Windows 10/11 설치 프로그램 |
| `REA-Studio-<버전>-portable.exe` | Windows 설치 없이 바로 실행 |

코드 서명 인증서(유료)를 쓰지 않았으므로 처음 실행할 때 경고가 뜹니다.

- **macOS**: 처음 열 때 차단되면 *시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"* 를 누릅니다. 그래도 안 되면 터미널에서 `xattr -cr "/Applications/REA Studio.app"` 를 실행합니다. 녹음하려면 마이크 권한을 허용하세요.
- **Windows**: SmartScreen 창이 뜨면 *추가 정보 → 실행* 을 누릅니다.

직접 빌드하려면 (각 운영체제에서):

```bash
npm ci
npm run dist:mac   # macOS에서 → dist/*.dmg, dist/*.zip
npm run dist:win   # Windows에서 → dist/*.exe
npm start          # 빌드 없이 데스크톱 창으로 실행
```

## 기능

| 영역 | 내용 |
| --- | --- |
| 트랜스포트 | 재생/정지, 녹음, 처음·끝으로, 마디 단위 이동, 루프 재생(끊김 없는 루프), 메트로놈, 마디\|박\|틱 ↔ 분:초 카운터 |
| 편집 창 | 멀티트랙 타임라인, 파형 표시, 눈금자(마디·시간), 그리드 스냅(1/4~1/32), 확대/축소, 마커 |
| 편집 도구 | **그래버**(이동·트랙 간 이동, 가장자리 드래그로 트림, 위쪽 모서리 드래그로 페이드 인/아웃), **셀렉터**(여러 트랙에 걸친 구간 선택), **가위**(클릭 위치에서 분할) |
| 클립 편집 | 분할, 구간 삭제, 복사/잘라내기/붙여넣기, 복제, 클립 게인, 빠른 페이드, 이름 변경, 실행 취소/다시 실행(200단계) |
| 녹음 | 트랙별 녹음 대기, AudioWorklet 기반 샘플 정확도 녹음, 출력 지연 자동 보정, 녹음 중 다른 트랙 재생 |
| 믹스 창 | 트랙별 채널 스트립(인서트 5슬롯, 팬, 페이더 −∞~+12 dB, 레벨 미터, 녹음/솔로/뮤트), 마스터 버스 |
| 이펙트 | 4밴드 EQ(하이패스 포함), 컴프레서, 에코 딜레이, 룸 리버브, 트림/위상 반전 — 바이패스 및 파라미터 편집 창 |
| 내보내기 | 바운스(오프라인 렌더링) → WAV 16/24-bit PCM, 32-bit float. 선택 구간 또는 세션 전체 |
| 저장 | 브라우저 자동 저장(IndexedDB, 새로고침해도 유지) + `.reaproj` 프로젝트 파일 저장/열기(오디오 포함) |
| 가져오기 | WAV, MP3, OGG, FLAC, M4A 등 브라우저가 디코딩할 수 있는 모든 형식. 드래그 앤 드롭 지원 |

## 기본 사용법

1. **오디오 가져오기** 버튼을 누르거나 파일을 타임라인으로 끌어다 놓습니다.
2. `Space` 로 재생/정지, 눈금자를 클릭해 위치를 옮깁니다.
3. 클립을 드래그해 옮기고, 가장자리를 끌어 길이를 줄이고, 위쪽 모서리를 끌어 페이드를 만듭니다.
4. `B` 로 재생 위치에서 자르고, `Delete` 로 지웁니다.
5. `=` 로 믹스 창을 열어 볼륨·팬·이펙트를 조절합니다.
6. **바운스…** 로 완성된 믹스를 WAV 파일로 저장합니다.

녹음: 트랙의 **●** 버튼을 켜고 `R` 을 누르면 현재 위치부터 녹음됩니다. `Space` 로 정지합니다.

전체 단축키는 프로그램에서 `?` 를 누르면 볼 수 있습니다.

## 구조

```
index.html        UI 레이아웃
css/style.css     테마
js/util.js        시간 표기, dB 변환, WAV 인코더, 파형 피크 계산
js/effects.js     인서트 이펙트 (Web Audio 노드 기반)
js/engine.js      오디오 엔진: 채널 스트립 그래프, 재생 스케줄링, 루프, 메트로놈, 녹음, 오프라인 바운스
js/editview.js    편집 창: 눈금자, 트랙 헤더, 타임라인 그리기와 마우스 편집
js/mixview.js     믹스 창: 채널 스트립, 인서트, 이펙트 편집 창
js/storage.js     IndexedDB 자동 저장
js/app.js         상태 관리, 실행 취소, 작업(분할/복사/…) , 파일 입출력, 단축키
desktop/main.js   데스크톱(Electron) 래퍼
.github/workflows/desktop.yml  macOS / Windows 자동 빌드
```

외부 라이브러리 없이 순수 JavaScript + Web Audio API 로만 작성되었습니다.
